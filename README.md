# Прототип ИИ-помощника оформления заказа

# Dev vetka

## Описание задачи

Цель проекта — создать прототип ИИ-помощника, который автоматизирует процесс оформления отправлений в СДЭК через предзаполнение формы на основе:
- фотографии отправляемого предмета, или
- текстового описания товара.

Помощник должен анализировать входные данные (изображение или текст), определять параметры упаковки, дополнительной упаковки, ценность посылки и рассчитывать стоимость доставки с использованием API СДЭК.

---

## User Stories

### A) Создание заказа по фото

1. Клиент запускает ИИ-помощника.
2. Нажимает кнопку «Фото».
3. Наводит камеру на предмет для отправки.
4. Система распознаёт изображение с помощью модели компьютерного зрения.
5. На основе распознанных объектов автоматически заполняется форма заказа, аналогичная форме в [Суперапп СДЭК](https://my.cdek.ru/lkfl/delivery).

### B) Создание заказа по описанию

1. Клиент вводит произвольное текстовое описание товара.
2. ИИ анализирует текст с помощью NLP-модели.
3. На основе анализа предзаполняется та же форма заказа.

---

## Поля для автоматического заполнения

### Основная упаковка (одна из):
- Коробка: XS, S, M, L
- Пакет: A4, A3, A2
- Конверт: A4
- Своя упаковка (если габариты не соответствуют стандартным)

### Дополнительная упаковка (зависит от типа основной упаковки):
- Внутренняя обрешётка
- Упаковочная бумага
- Воздушно-пупырчатая плёнка
- Прессованный картон

> **Примечание:** Доступные опции дополнительной упаковки зависят от выбранной основной упаковки и типа товара (например, хрупкий, мягкий, жёсткий и т.д.).

---

## Бонусные требования

1. **Определение ценности посылки**  
   ИИ должен оценивать стоимость товара на основе изображения или описания и предзаполнять поле «Ценность».

2. **Обработка нескольких предметов**  
   Если на фото распознано несколько предметов:
   - Сгруппировать их оптимально по упаковкам.
   - Назначить соответствующую дополнительную упаковку для каждого типа предмета.
   - Сформировать несколько отправлений при необходимости.

3. **Расчёт стоимости доставки**  
   Использовать API СДЭК для расчёта тарифа:  
   `POST https://my.cdek.ru/api/lkfl/v2/calculator/calculateTariff`  
   Подробности — в разделе ["Входные данные"](https://confluence.cdek.ru/pages/viewpage.action?pageId=20644051) (требуется авторизация).

## Техническая реализация (план)

### 1. Фронтенд
- Простой интерфейс на HTML/CSS/JS или React:
  - Кнопка «Сделать фото» с доступом к камере
  - Поле ввода текста
  - Отображение предзаполненной формы
  - Отображение расчёта стоимости

### 2. Бэкенд / Логика
- Модель распознавания изображений (например, YOLO, CLIP или предобученная модель через Hugging Face)
- NLP-обработка текста (например, с использованием spaCy или LLM)
- Логика выбора упаковки на основе размеров и типа товара
- Интеграция с API СДЭК для расчёта тарифа

### 3. Интеграция с API СДЭК
- Авторизация через OAuth или токен
- Отправка данных о весе, габаритах, откуда/куда
- Получение и отображение стоимости доставки
